# Figure 04, text through the weights

`04-text-through-weights.png`

Connects the file from figure 03 to the thing the audience already uses every
day. After this figure, "a chatbot" and "a file of numbers" should be the same
object in their head.

A single left-to-right pipeline:

```
YOUR PROMPT  ->  TOKENS  ->  [ WEIGHTS ]  ->  NEXT TOKEN  ->  RESPONSE
```

- `YOUR PROMPT`, a short text bubble.
- `TOKENS`, the text broken into small labeled chunks.
- `WEIGHTS`, a large central block drawn as a stack of the same grid motif used
  in figure 03 panel 3, so the two figures read as the same object. This block
  is the subject of the figure and should dominate it.
- `NEXT TOKEN`, a single chunk leaving the block.
- `RESPONSE`, a text bubble.

A feedback arrow loops from `NEXT TOKEN` back to the input side of the weights
block, labeled `ONE TOKEN AT A TIME`, showing the loop that produces a whole
response.

No accent color. Nothing here constrains the user yet, that comes later when
the same block appears behind a gateway someone else owns.
