## Gotchas (learned the hard way)

- **MDX autolinks**: `<https://url>` breaks compile (MDX reads `<...>` as JSX).
  Use `[text](url)` or bare URLs. A compile error → the post page 404s
  (`getBlogPost` throws → `notFound()`), while the index still lists it.
- **Nav alignment**: `ch` width scales with `font-size` — setting `font-size`
  on a `ch`-width container shifts it inward. Put font-size on the links, not
  the container.
- **Dark code**: `rehype-pretty-code` `theme: { light, dark }` emits
  `--shiki-light`/`--shiki-dark` per token; CSS switches
  `pre code[data-theme*=" "] span` color under `.dark`. `keepBackground:false`
  so the block bg comes from the `--code-bg` token.
- **next-themes**: `suppressHydrationWarning` on `<html>`; toggle uses a
  `mounted` check to avoid hydration mismatch.
- Peekaboo drives screenshots: `--app "Google Chrome"` (not `frontmatter`),
  window-relative `--coords`, `peekaboo scroll --direction down --amount N`.
